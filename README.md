#  Kişisel Portfolio Web Sitesi

##  Proje Özeti

Bu proje, Kapadokya Üniversitesi Bilişim Sistemleri ve Teknolojileri bölümü öğrencisi Semih Berke Kolatan'ın kişisel portfolio web sitesidir. Modern, responsive ve kullanıcı dostu bir tasarımla hazırlanmıştır.

##  Tasarım Özellikleri

- **Renk Teması**: Krem ve Kahverengi tonları
- **Tasarım Stili**: Modern, minimalist ve şık
- **Responsive**: Tüm cihazlarda uyumlu çalışır

##  Kullanılan Teknolojiler

- **HTML5**: Semantik web yapısı
- **CSS3**: Modern stil ve animasyonlar
- **JavaScript**: İnteraktif özellikler

##  Özellikler

### 1. Ana Sayfa (Hero)
- Profil fotoğrafı
- Karşılama metni
- Kişisel tanıtım

### 2. Hakkımda Bölümü
- Eğitim bilgileri
- Kısa özgeçmiş

### 3. Yetenekler Bölümü
- HTML
- Unity
- Unreal Engine
- C# 

### 4. Projeler Bölümü
- TÜBİTAK 2209 - Akıllı Sera Sistemi
- Oyun Geliştirme Projeleri

### 5. İletişim Bölümü
- İletişim formu
- E-posta gönderme
- Sosyal medya bağlantıları

### 6. Footer
- Telif hakları
- Sosyal medya linkleri (Gmail, LinkedIn, Instagram)

### Smooth Scroll
- Menü linklerine tıklandığında sayfada yumuşak geçişler

### Form Validasyonu
- İletişim formunda otomatik doğrulama
- Başarılı gönderim mesajı (3 saniye görünür)

### Hover Efektleri
- Kartlara ve butonlara mouse ile gelince animasyonlar
- Sosyal medya ikonlarında büyütme efekti

### Responsive Tasarım
- Mobil, tablet ve masaüstü uyumlu
- 768px altında tek sütun düzeni
